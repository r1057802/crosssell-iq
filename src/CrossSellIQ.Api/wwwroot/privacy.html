Privacy Policy

Last updated: 20 November 2026

This page describes how the application works today. It has not been reviewed by a legal expert, and it does not claim compliance with the GDPR or any other law.

Who runs this website

CrossSellIQ is a student project by Nicolas Diaz Valencia for the Cloud & Ops and Artificial Intelligence courses at Thomas More. It is a demo, not a commercial service.

Contact: r1057802@student.thomasmore.be

Which data the application shows

The recommendations are based on the public Kaggle dataset "H&M Personalized Fashion Recommendations". In this dataset, customers are identified by a 64-character hash instead of a name. The application shows, per hashed customer ID, which product categories were bought and which popular categories were not. It does not contain names, addresses, or contact details.

Data you enter

When you enter a customer ID or select an example customer, your browser sends that ID to the CrossSellIQ API to look up the recommendations. The application does not store the IDs you enter and does not write them to its own logs.

Cookies, accounts, and tracking

  • The website does not use cookies.
  • There are no user accounts and no login.
  • There are no analytics, advertising, or tracking tools. The page only loads files from its own domain; no scripts, fonts, or images come from other websites.

Technical logs

The application runs on Microsoft Azure Container Apps in the Germany West Central region. Error messages from the application and technical logs from the Azure platform are stored in an Azure Log Analytics workspace, so problems can be investigated.

These logs are kept for 30 days and then deleted automatically.

Legal basis

The data described above is processed on the basis of legitimate interest (Article 6(1)(f) of the GDPR): to look up the recommendations you ask for, and to keep the application secure and working. The website does not ask for consent, because it uses no cookies, tracking, or accounts.

Service providers

  • Microsoft Azure: hosting of the application and its database, and the technical logs.
  • GitHub: source code and the container image of the application. GitHub does not receive the data you enter on this website.

Where the data is processed

The application, its database, and its logs run in the Microsoft Azure Germany West Central region, inside the European Union. CrossSellIQ itself does not transfer data you enter to countries outside the European Union. How Microsoft processes data within its own services is described in the Microsoft Privacy Statement.

Your rights

Under the GDPR, you can ask to:

  • see which data about you is processed (access);
  • correct data that is wrong (rectification);
  • delete data (erasure);
  • limit how data is processed (restriction);
  • object to processing based on legitimate interest (objection).

In practice, the application does not store the customer IDs you enter, and the technical logs are deleted automatically after 30 days. Send questions or requests to r1057802@student.thomasmore.be.

Complaints

If you think your data is not handled correctly, you can file a complaint with the Belgian Data Protection Authority (Gegevensbeschermingsautoriteit): www.dataprotectionauthority.be.

Changes

This page is updated when the application changes how it handles data. The date at the top shows the latest version.
